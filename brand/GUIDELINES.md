# Tessera logo — usage guide

**The idea:** three window panes whose gutters spell the **T** of Tessera. The blue pane is the focused window,
the same blue as Tessera's focus border.

## Files

| File | Use |
|---|---|
| `logo/tessera-symbol.svg` | The mark on light backgrounds |
| `logo/tessera-symbol-reversed.svg` | The mark on dark backgrounds |
| `logo/tessera-horizontal(-reversed).svg` | Default lockup: README, website header, docs |
| `logo/tessera-stacked(-reversed).svg` | Square-ish spaces: posters, stickers, about pages |
| `logo/tessera-wordmark(-reversed).svg` | Name only, when the mark is already nearby |
| `logo/*-black.svg`, `logo/*-white.svg` | One-colour print, engraving, single-colour UI |
| `logo/tessera-app-icon.svg` | App icon / avatar: the mark on a dark tile, works on any background |
| `icons/tessera-16…32(-reversed).svg` | Pixel-snapped small cuts — use these below 48 px, never a scaled-down master |
| `icons/favicon.ico`, `../src/icons/*.ico` | Favicon; the app's exe and tray icons (built into `Tessera.exe`) |

Everything is generated by `build_logo.py`; change the geometry there, never by hand in the SVGs.

## Colour

| Name | HEX | RGB | Use |
|---|---|---|---|
| Ink | `#1B1F24` | 27 31 36 | Panes and wordmark on light backgrounds; app-icon tile |
| Tessera Blue | `#0078D4` | 0 120 212 | Focused pane on light backgrounds |
| Paper | `#F3F4F6` | 243 244 246 | Panes and wordmark on dark backgrounds |
| Sky | `#4CC2FF` | 76 194 255 | Focused pane on dark backgrounds |

Only one pane is ever blue: the lower right. In one colour, all three panes take the same colour — the T in the gaps
still carries the mark.

## Spacing and size

- **Clear space:** keep at least one gutter width (the width of the T's stem) free on every side of the mark,
  and two gutter widths around a lockup.
- **Horizontal lockup:** the wordmark's x-height equals the height of the lower panes and sits on their baseline.
  Don't re-space or rescale the parts; use the file.
- **Minimum size:** symbol 16 px (with the 16 px cut); horizontal lockup 96 px wide; stacked lockup 48 px wide.
- **Wordmark type:** Lato Bold (SIL Open Font License), converted to outlines, tracking −10/1000. For running text
  next to the logo, use the platform font (Segoe UI Variable on Windows).

## Backgrounds

Light backgrounds take the standard version; dark ones (taskbar in dark mode, dark README theme) take the reversed
version. On photos or mid-tone colours, use the app icon (tile) instead of the bare mark.

## Don't

- Don't make more than one pane blue, or swap which pane is blue.
- Don't close or narrow the gutters — they are the T.
- Don't add outlines, shadows, gradients or glass effects.
- Don't rotate, mirror or rearrange the panes into a 2×2 grid (that reads as the Windows logo).
- Don't scale the 256 px master below 48 px; use the pixel-snapped cuts.
- Don't set the name in another font or in capitals as part of the logo.
